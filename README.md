# CR Gestoría

Sitio web profesional para servicios de gestoría integral.

## 🏢 Sobre CR Gestoría

Empresa dedicada a servicios integrales de:
- Asesoría fiscal
- Gestión administrativa
- Cumplimiento normativo
- Consultoría empresarial

## 🛠️ Stack Tecnológico

- **Frontend**: Next.js 16 + React 19 + TypeScript
- **Styling**: Tailwind CSS 4
- **Deployment**: Vercel
- **Performance**: Optimizado

## 📑 Secciones

- **Hero**: Presentación de servicios
- **Servicios**: Detalle de ofertas
- **Sobre Nosotros**: Información corporativa
- **Contacto**: Formulario para consultas
- **Footer**: Información de contacto

## 🚀 Inicio Rápido

```bash
# Clonar repositorio
git clone https://github.com/djpinto2/cr-gestoria.git
cd cr-gestoria

# Instalar dependencias
npm install

# Desarrollo
npm run dev

# Build para producción
npm run build
npm start
```
